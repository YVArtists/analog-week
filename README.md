# Analog Week at Desert Doghouse

Static landing page for Analog Week (November 30 to December 3, 2026).

- `index.html` is the whole page; images are in `img/`, videos in `vid/`.
- Hosted with GitHub Pages from the `main` branch, root folder.
- To edit: change the files and push to `main`; Pages redeploys in a minute or two.
